# EE 2300 visual coverage matrix

This matrix follows Iowa State's catalog scope and will be refined with the
student's uploaded syllabus and lecture notes.

| Area | Required visual explanations |
|---|---|
| Frequency domain | impedance substitution, transfer-function derivation, poles/zeros, Bode magnitude and phase |
| Sinusoidal steady state | rotating phasors, amplitude/phase propagation, complex arithmetic |
| Time domain | RC/RL/RLC transients, initial/final conditions, energy exchange, differential-to-Laplace transition |
| Linearization | operating point, tangent approximation, large-signal to small-signal model |
| Feedback and stability | loop flow, negative/positive feedback, loop gain, pole motion, stability margins |
| Operational amplifiers | virtual short, KCL, common topologies, finite gain/GBW, saturation, slew rate |
| Nonlinear circuits | diode states, rectifiers, clipping, piecewise transfer curves, distortion |
| Transfer realizations | cascade/block diagrams, active-filter realization, stage loading |
| Data converters | ADC quantization, DAC reconstruction, code transitions, LSB, clipping |
| Converter quality | INL, DNL, missing codes, SNR/SINAD/ENOB, harmonic spectra |
| Sampling | sample/hold, spectral replicas, aliasing, reconstruction |
| Sources and distortion | offsets, noise, harmonics, intermodulation, loading |
| Instrumentation | oscilloscope, DMM, generator, probes, grounding, expected versus measured |
| Laboratory workflow | breadboard topology, test points, parameter sweep, fault localization, uncertainty |

## Cross-cutting math primitives

- Equation write-on, alignment, substitution, cancellation, and rearrangement
- Fractions, superscripts, subscripts, matrices, piecewise forms, and units
- Cartesian, logarithmic, complex-plane, polar, and spectral plots
- Synchronized highlighting between a symbol, circuit part, and graph trace
- Step captions that state both the operation and the physical reason
